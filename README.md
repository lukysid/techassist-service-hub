# TechAssist Service Hub

Crie a primeira versão do meu projeto TechAssist.

É um sistema web para gerenciamento de uma assistência técnica de informática.

Utilize React, TypeScript e Tailwind CSS.

Quero uma interface moderna, profissional e responsiva, com:

Menu lateral azul e branco.

Cabeçalho com nome TechAssist.

Dashboard com indicadores de clientes, ordens abertas e ordens finalizadas.

Página de clientes.

Página de ordens de serviço.

Neste primeiro momento, concentre-se na estrutura visual, navegação entre páginas e organização dos componentes.

Crie formulários para cadastro de clientes e ordens de serviço.

Não implemente banco de dados externo ainda.
Não utilize Supabase ou Firebase.
Não invente integração com APIs.

Prepare a estrutura do código para futuramente integrar com uma API REST externa que utiliza JSON.

Quero um sistema profissional, com boa experiência de uso e visual limpo.
